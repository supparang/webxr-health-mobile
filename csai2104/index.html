ระดับ (Rank): แต้มหลักฐาน (EP): ความสมบูรณ์ (Integrity):
แนะนำเส้นทางภารกิจ (Campaign Briefing)

สร้างระบบ → ทดสอบปัญหา → พิสูจน์ด้วยหลักฐาน → แก้ไขให้ปลอดภัย

คุณคือวิศวกรซอฟต์แวร์ปัญญาประดิษฐ์ ภารกิจของคุณคือพัฒนาระบบตั้งแต่การค้นหาความต้องการ การออกแบบ การทดสอบ การปล่อยใช้ ไปจนถึงการจัดการการเปลี่ยนแปลงอย่างมีหลักฐาน

เส้นทางภารกิจ: ความต้องการ (Need) → ข้อกำหนด (Requirement) → ออกแบบ (Design) → ทดสอบ (Test) → ปล่อยใช้ (Release) → เปลี่ยนแปลง (Change)

เลือกภารกิจด้านล่างเพื่อเริ่มหรือทบทวน โดยดำเนินตามลำดับ ภารกิจ (Mission) → ห้องฝึกปฏิบัติ (Practice Lab) → โจทย์ท้าทาย (Challenge) → หลักฐาน (Evidence) → ผ่านด่าน (Clear) นักศึกษาตอบเป็นภาษาไทย อังกฤษ หรือผสมกันได้ โดยเน้นความถูกต้องของเหตุผลและหลักฐาน

สถานะและคะแนนในเกมเป็นผลฝึกในเครื่อง ไม่ใช่คะแนนทางการ และยังต้องรอผู้สอนตรวจรับรองหลักฐาน
