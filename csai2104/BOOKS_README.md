# CSAI2401 หนังสืออ้างอิง

เกมใช้รายการหนังสือใน `references.json` เพื่อจับคู่หัวข้ออ่านกับ W1–W15 และไม่จำเป็นต้องอ่านทุกเล่มก่อนเริ่มภารกิจ

ไฟล์ PDF ที่ผู้สอนแนบไว้ยังคงอยู่ในคลังภายในเครื่องที่ระบุโดยผู้สอน แต่ไม่ได้คัดลอกเข้า public repository เพราะสิทธิ์เผยแพร่ของ BookFi, PDFDrive และฉบับตำราเชิงพาณิชย์ยังไม่มีหลักฐานในงานนี้ การนำไฟล์ขึ้น public GitHub จะทำให้บุคคลทั่วไปดาวน์โหลดซ้ำได้

หากผู้สอนมีสิทธิ์เผยแพร่หรือใช้ไฟล์ open-license ให้เพิ่ม `license` และ `authorizedAssetUrl` ใน `references.json` ก่อน แล้วจึงวางไฟล์ไว้ใน `csai2104/books/` และเพิ่มลิงก์จาก Reading Shelf
