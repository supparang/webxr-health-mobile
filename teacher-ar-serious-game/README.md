# Teacher AR Serious Game Creator — Demo Arena

HeroHealth-style workshop demos for teachers.

## Start
Open `teacher-ar-serious-game/START-HERE.html` through GitHub Pages.

## Demos
- Eco Sort Hero — Hand pinch drag/drop + Touch fallback
- Word Catcher — Hand catch + Touch fallback
- Math Slash — Hand hit + Touch fallback
- Matter Lab Rescue — Hand pinch drag/drop + Touch fallback
- Move & Learn Adventure — MediaPipe Pose (Lean / Jump / Duck / Balance)

## Design principle
Question → Action → Mission → Feedback → Boss → Evidence

## Technical notes
- Camera interaction should be served through HTTPS.
- Internet access is required for MediaPipe CDN.
- Hand games retain Touch/Mouse fallback for classroom resilience.
