# ACTIVA-AI V0.3.7 — Evidence Integrity and Review Governance

## 1. Two-layer status
System Evidence Status และ Final Human Decision เป็นคนละตัวแปรเสมอ

System Evidence:
- COMPLETE
- INCOMPLETE
- REVIEW_REQUIRED

Final Decision:
- VERIFIED
- OVERRIDE_VERIFIED
- REVIEW_REQUIRED
- REJECTED
- PENDING

Human decision ห้ามเขียนทับ System Evidence Status

## 2. Normal verification gate
VERIFY ปกติทำได้เมื่อ:
- Evidence Evaluation ถูกทำแล้ว
- ไม่มี missingCodes
- ไม่มี reasonCodes
- System Evidence = COMPLETE

## 3. Manual Override
ถ้ายังมี blocker แต่จำเป็นต้องรับรอง:
- เฉพาะ ADMIN
- decision = OVERRIDE_VERIFY
- ต้องมีเหตุผลอย่างน้อย 10 ตัวอักษร
- final status = OVERRIDE_VERIFIED
- เก็บ blockers + reason ใน Audit Trail

## 4. Stale decision invalidation
เมื่อ evidence เปลี่ยนภายหลัง เช่น Check-out หรือ Staff Verification ระบบล้าง final decision เดิมที่อาจไม่ทันสมัยและบันทึก FINAL_DECISION_INVALIDATED

OVERRIDE_VERIFIED ไม่ถูกเปลี่ยนอัตโนมัติจากการ re-evaluate เพราะเป็น explicit governance decision และยังคงแสดง System Evidence แยกต่างหาก

## 5. Duplicate/incorrect record repair
ใช้ Void แทน Delete:
- ADMIN/STAFF เลือกรายการ
- ระบุเหตุผล
- record ยังคงอยู่เพื่อ Audit
- แต่ไม่ถูกใช้ใน Dashboard, Ground Truth, ML หรือ Research Export

## 6. Mobile UX
รายการ Attendance และ Evidence แสดงเป็น card บนหน้าจอมือถือ และตารางเต็มใช้บนจอใหญ่
