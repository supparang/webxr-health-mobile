# ACTIVA-AI V0.5.1 — Role / Permission Terminology Pass

## เป้าหมาย
ลดความสับสนระหว่าง “ประเภท/บทบาทของบุคลากร” กับ “สิทธิ์จัดกิจกรรม”

## คำเรียกใน UI
- ADMIN → ผู้ดูแลระบบ
- ORGANIZER → บุคลากรที่ได้รับสิทธิ์จัดกิจกรรม (compatibility role เดิม)
- STAFF → ผู้ตรวจสอบหลักฐาน
- PARTICIPANT → บุคลากรผู้เข้าร่วมกิจกรรม

## หลักการ
สิทธิ์สร้างหรือจัดกิจกรรมไม่ได้อนุมานจากการเป็นอาจารย์หรือเจ้าหน้าที่สายสนับสนุน แต่ ADMIN เป็นผู้เพิ่ม/ลด Activity Permissions รายบุคคล
