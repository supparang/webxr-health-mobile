# ACTIVA-AI V0.2 API

V0.2 เปลี่ยนแกนระบบจาก localStorage ไปสู่ server-side API + PostgreSQL โดยยังคง V0.1 static UI ไว้เพื่อสาธิต

## Endpoints
- GET /api/health
- GET /api/activities
- POST /api/activities
- POST /api/activities/:activityId/qr
- POST /api/attendance/checkin
- POST /api/attendance/:attendanceId/checkout
- POST /api/attendance/:attendanceId/staff-verify
- POST /api/evidence/:attendanceId/evaluate
- POST /api/reviews/:attendanceId
- GET /api/ground-truth/queue
- POST /api/ground-truth/:attendanceId/labels
- GET /api/research/export

## User Context
Prototype API ใช้ header:
x-activa-user-id: <database user id>

ใน production ต้องเปลี่ยนเป็น institutional authentication / SSO และ role-based authorization ที่ฝั่ง server

## Dynamic QR
QR token ลงลายมือชื่อด้วย HMAC-SHA256 และมี:
- eventId
- issued time
- expiry
- nonce
- key version

ห้ามใส่ PII ของผู้เข้าร่วมไว้ใน QR

## AI Status
V0.2 ยังไม่เปิด AI prediction โดยอัตโนมัติ จนกว่าจะ:
1. ล็อก ground-truth codebook
2. เก็บข้อมูลเพียงพอ
3. แยก train/validation/test
4. ประเมิน baseline และ calibration

Rule-based evidence evaluation ต้องระบุว่าไม่ใช่ AI probability
