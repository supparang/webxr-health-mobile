# ACTIVA-AI V0.9.0 — Pilot Readiness & Operational Monitoring

## เป้าหมาย
ทำให้ทีมตอบคำถามก่อนเปิด Pilot ได้อย่างเป็นระบบว่า:
1. มีปัญหา Data Quality ระดับวิกฤตหรือไม่
2. Review Queue ค้างนานเกินเป้าหมายหรือไม่
3. กิจกรรมที่จบแล้วพร้อมปิดเชิงกระบวนการหรือไม่
4. Governance safeguards ที่ตกลงไว้ยังอยู่ครบหรือไม่

## Endpoint
`GET /api/operations/pilot-readiness`

สิทธิ์:
- ADMIN
- STAFF

Participant ได้ 403

Response:
- `aggregated: true`
- `containsPII: false`

## Pilot status
### READY
ไม่มี critical data-quality issue, ไม่มี backlog เกิน target, ไม่มี warning และไม่มีกิจกรรมสิ้นสุดที่ยังไม่ close-ready

### WATCH
ไม่มี critical issue แต่มีอย่างน้อยหนึ่งกรณี:
- Review backlog เกิน monitoring target
- Data Quality warning
- กิจกรรมที่จบแล้วยังไม่ close-ready

### BLOCKED
พบ Data Quality ระดับ CRITICAL

สถานะนี้เป็น readiness ของกระบวนการ ไม่ใช่การจัดอันดับบุคลากร

## Review backlog aging
Backlog นับเฉพาะ:
- record ที่มี Evidence Evaluation แล้วแต่ยังไม่มี terminal Human Decision หรือ
- กิจกรรมสิ้นสุดแล้วแต่ record ยังไม่ได้ Evidence Evaluation

Queue age:
- ถ้ามี ConsistencyResult: เริ่มที่ `evaluatedAt`
- ถ้ายังไม่มีและกิจกรรมจบ: เริ่มที่ `activity.endAt`

Buckets:
- < 4 ชั่วโมง
- 4–24 ชั่วโมง
- 24–48 ชั่วโมง
- ≥ 48 ชั่วโมง

## Monitoring target
Environment variable:
`REVIEW_TARGET_HOURS`

ค่าเริ่มต้น:
24 ชั่วโมง

ระบบระบุ explicit ว่า:
`OPERATIONAL_MONITORING_TARGET_NOT_PERSONNEL_SCORE`

## Data Quality rules
### CRITICAL
- DUPLICATE_NONVOID_ATTENDANCE
- CHECKOUT_BEFORE_CHECKIN
- FINAL_STATUS_WITHOUT_HUMAN_REVIEW
- NORMAL_VERIFY_WITH_SYSTEM_BLOCKERS

### WARNING
- HUMAN_REVIEW_REASON_MISSING
- ENDED_ACTIVITY_RECORD_NOT_EVALUATED

## Activity closing checklist
สำหรับกิจกรรมที่สิ้นสุดแล้ว:
- ACTIVITY_ENDED
- ALL_RECORDS_EVALUATED
- NO_UNRESOLVED_HUMAN_REVIEW
- NO_CRITICAL_DATA_QUALITY

`closeReady=true` เมื่อผ่านครบทุกข้อ

V0.9 ยังไม่ lock หรือ mutate activity จริง
เพื่อให้ Pilot acceptance ตรวจสอบได้ก่อนเพิ่ม irreversible workflow

## Governance checks
- Human final decision required = true
- AI autonomous decision = false
- Ground Truth blinded from AI during labeling = true
- Analytics aggregate-only = true
- AI required for pilot = false

เหตุผล:
AI เป็น decision support layer ไม่ใช่ข้อกำหนดพื้นฐานของ trusted participation verification

## UI

Verification → Pilot Readiness

หน้า Pilot Readiness แสดง:
- Overall pilot status
- Review backlog + aging
- Over-target count
- Data Quality alerts
- Governance gate
- Activity closing checklist

## Privacy
Operational monitoring ไม่ส่ง:
- employeeId
- ชื่อบุคลากร
- รายละเอียด case รายบุคคล

หากต้องแก้ case จริง ผู้ตรวจต้องกลับไป Human Review Queue ซึ่งมี access control แยกต่างหาก
