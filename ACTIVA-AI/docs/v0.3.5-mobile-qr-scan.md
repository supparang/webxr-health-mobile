# ACTIVA-AI V0.3.5 — Mobile QR Scanner

## User flow
Participant → Check-in → สแกน QR → Allow Camera → เล็ง Dynamic Event QR → Token decoded → Check-in API → Success

## Mobile requirements
- HTTPS หรือ localhost
- Camera permission
- แนะนำกล้องหลัง (environment-facing camera)

## Demo Mode
Dynamic QR ของ Demo Mode เป็น token ที่มี event id และเวลาที่ออก token จึงทดลองข้ามอุปกรณ์ได้ แม้แต่ละเครื่องจะมี localStorage คนละชุด
Token มีอายุ 45 วินาที

## Fallback
หากกล้องใช้งานไม่ได้ ผู้ใช้ยังสามารถเลือก "กรอก/วาง Token" ได้

## Production note
Demo token ไม่ใช่ cryptographic production token; Server Mode ยังคงใช้ signed token ฝั่ง server
