# ACTIVA-AI V0.3.6 — Duplicate Attendance Prevention

สำหรับกิจกรรมแบบ single-session ใน prototype กำหนดว่า 1 participant มี AttendanceRecord ได้เพียง 1 รายการต่อ Activity

## State behavior
- ไม่มี record → Check-in ได้
- มี record และยังไม่ Check-out → ALREADY_CHECKED_IN
- มี record และ Check-out แล้ว → ACTIVITY_ALREADY_COMPLETED
- Check-out ซ้ำ → ALREADY_CHECKED_OUT

หลัง ACTIVITY_ALREADY_COMPLETED ผู้ใช้ไม่ควรสร้าง record ใหม่ แต่ workflow ไปต่อที่ Staff Verification → Evidence Evaluation → Human Review

## Database safeguard
Server Mode เพิ่ม unique(activityId, userId)

หากในอนาคตรองรับกิจกรรมหลาย session ควรเพิ่ม ActivitySession แล้วใช้ unique(activitySessionId, userId) แทนการยอมให้ duplicate records ใน Activity เดียว
