# ACTIVA-AI V0.3.1 — Ground Truth Adjudication and AI Readiness

## Reviewer isolation
ผู้ประเมินบทบาท STAFF จะได้รับเฉพาะ label ของตนเองจาก Ground Truth queue เพื่อรักษาความเป็นอิสระของการตัดสิน

Ground Truth workspace ไม่ส่ง:
- AI prediction
- risk probability
- rule-based consistency result

ผู้ประเมินจึงพิจารณาจาก raw evidence และ codebook เท่านั้น

## Adjudication
Admin สามารถเห็น independent labels หลังจากถูกบันทึกแล้ว และใช้ขั้นตอน:
Independent Labels → Adjudicate → Lock

ถ้าผู้ประเมินไม่ตรงกัน ระบบบังคับให้ใส่ adjudication note

## Lock
เมื่อ status = LOCKED:
- ห้ามแก้ independent label
- ห้าม re-adjudicate
- record จึงเข้า ML dataset ได้

## AI Readiness Dashboard
แสดง:
- จำนวน independent labels
- adjudicated cases
- locked cases
- REVIEW_REQUIRED
- NO_REVIEW_REQUIRED

Dashboard ไม่ใช้จำนวนคงที่ตัดสินว่า sample "เพียงพอ" เพราะเกณฑ์ sample adequacy ต้องมาจาก research protocol และ primary endpoint

## ML Dataset
ดาวน์โหลดจาก /api/ml/dataset เฉพาะ LOCKED Ground Truth
- de-identified participant hash
- ไม่มี AI prediction
- ไม่มี risk probability
- ใช้สำหรับ offline model development/evaluation
