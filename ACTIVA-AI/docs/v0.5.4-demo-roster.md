# ACTIVA-AI V0.5.4 — Demo Personnel Roster

Demo Mode มีบัญชีพร้อมใช้:
- ADM001 — ผู้ดูแลระบบ
- ORG001 — บุคลากรที่ได้รับสิทธิ์จัดกิจกรรม
- STF001 — ผู้ตรวจสอบหลักฐาน
- P001–P003 — ผู้เข้าร่วมตัวอย่างเดิม
