## P3.2.1 External Blind Reviewer Access

When additional persistent STAFF/Google accounts are unavailable, ADMIN may create a two-link external review batch for an eligible attendance record. Reviewer A and B must be two different real people. Independence is attested, not identity-verified. See `v1.1.0-phase3-external-blind-review.md`.

This capability removes an account-availability blocker but does not fabricate Ground Truth and does not permit one person to act as both independent reviewers.
