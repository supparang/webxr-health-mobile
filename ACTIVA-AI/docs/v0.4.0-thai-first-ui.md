# ACTIVA-AI V0.4.0 — Thai-First Operational UI

หน้าจอสำหรับผู้ปฏิบัติงานใช้ภาษาไทยเป็นหลัก ขณะที่ code ภายในยังคงเดิมเพื่อความคงที่ของฐานข้อมูล งานวิจัย และ Audit

ตัวอย่าง:
- REVIEW_REQUIRED → ต้องตรวจสอบ
- PENDING → รอการตัดสิน
- VERIFIED → รับรองแล้ว
- OVERRIDE_VERIFIED → รับรองเป็นกรณีพิเศษ
- SHORT_DURATION → ระยะเวลาเข้าร่วมไม่ถึงเกณฑ์

รหัสเดิมยังเข้าถึงได้จาก title/data-code หรือส่วน “ดูรหัสทางเทคนิค”
