# ACTIVA-AI V0.7.0 — AI Risk Prioritization in Human Review Queue

## เป้าหมาย
เชื่อมผลพยากรณ์จาก deployed model เข้ากับ Review Queue ที่เจ้าหน้าที่ใช้จริง โดย AI ทำหน้าที่จัดลำดับและอธิบาย ไม่ทำหน้าที่ตัดสินแทนมนุษย์

## Workflow
Evidence → Rule Evaluation → AI Risk/XAI → Prioritized Review Queue → Human Decision → Audit Trail

## หลักการจัดคิว
เมื่อมี deployed model และ prediction:
1. แยก case ที่ยังรอดำเนินการออกจากประวัติที่ตัดสินแล้ว
2. ภายในกลุ่ม Pending เรียง riskProbability จากมากไปน้อย
3. ถ้าไม่มี AI score ใช้ workflow/evidence priority และเวลาตามเดิม
4. AI ranking ไม่เปลี่ยน Evidence Status หรือ Final Status

## Metadata จาก /api/xai/queue
แต่ละ prediction เพิ่ม:
- priorityRank
- riskPercent
- modelFlaggedForReview

Response ระบุ:
- decisionSupportOnly: true
- rankingBasis: deployed_model_risk_probability_desc

## Review Queue
เจ้าหน้าที่เห็นพร้อมกัน:
- Workflow Status
- System Evidence Status
- Final Human Status
- AI Priority %
- AI predicted label

## Review Case
เมื่อเปิด case จะแสดง:
- Priority rank
- Risk probability
- Predicted label
- Model version
- Local predictive explanation
- คำเตือนว่า explanation ไม่ใช่ causal conclusion และ AI ไม่เปลี่ยนผลรับรองอัตโนมัติ

## Governance safeguards
- Human reviewer เป็นผู้ตัดสินสุดท้าย
- VERIFY / CORRECT / REQUEST_EVIDENCE / REJECT ยังใช้ workflow เดิม
- Manual override ยังคงเป็น ADMIN-only
- Ground Truth labeling ไม่ได้รับ AI prediction หรือ rule recommendation
- ระบบยังใช้งานได้เมื่อไม่มี deployed model
- AI result เป็น decision support ไม่ใช่ข้อกล่าวหาเกี่ยวกับบุคคล

## QA
Smoke test เพิ่ม prediction สองระดับ:
- 0.84 → REVIEW_REQUIRED
- 0.32 → NO_REVIEW_REQUIRED

ต้องตรวจว่า:
- queue เป็น decisionSupportOnly
- rankingBasis ถูกต้อง
- riskPercent ถูกต้อง
- modelFlaggedForReview ถูกต้อง
- เคส 0.84 มี priorityRank ก่อนเคส 0.32
- AI prediction ไม่เปลี่ยน finalEvidenceStatus
