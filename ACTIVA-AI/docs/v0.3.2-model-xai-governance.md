# ACTIVA-AI V0.3.2 — Model Evaluation and XAI Governance

## Model lifecycle
CANDIDATE → EVALUATED → APPROVED → DEPLOYED → RETIRED

แต่ละขั้นแยกจากกันเพื่อป้องกันการนำโมเดลที่เพิ่งฝึกเสร็จไปใช้กับบุคลากรทันที

### EVALUATED
มีผล validation/test evaluation ที่ import จาก offline ML pipeline

### APPROVED
ผู้ดูแลที่ได้รับสิทธิ์ตรวจผลการประเมินและอนุมัติด้าน governance

### DEPLOYED
โมเดลสามารถส่ง prediction เข้าสู่ AI/XAI Review Workspace ได้

## Synthetic safeguard
โมเดลที่ dataProvenance = SYNTHETIC_CI_ONLY จะ deploy ไม่ได้ตามค่าเริ่มต้น
ยกเว้น environment สำหรับ CI ที่กำหนด ALLOW_SYNTHETIC_CI=true

## Prediction behavior
Prediction ประกอบด้วย:
- modelVersion
- predictedLabel
- riskProbability
- explanation

การ import prediction:
- ต้องมาจาก DEPLOYED model
- probability ต้องอยู่ 0–1
- ไม่เปลี่ยน finalEvidenceStatus
- ไม่ตัดสินผลด้านบุคลากรอัตโนมัติ

## XAI Workspace
แสดง Risk + Explanation เป็น decision support
Human reviewer ยังคงเป็นผู้ตัดสินใจสุดท้าย

Explainability ไม่ตีความเป็น causality และไม่ใช้เป็นข้อกล่าวหาเรื่องการทุจริต
