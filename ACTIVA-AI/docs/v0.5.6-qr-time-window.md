# ACTIVA-AI V0.5.6 — QR Check-in Time Window Enforcement

## เงื่อนไข Check-in ที่ต้องผ่านทั้งหมด
QRValid
AND InCheckinWindow
AND ParticipantAllowed
AND IdentityMatched
AND NoExistingAttendance

## ค่าเริ่มต้น
- Check-in Open = Activity Start - 30 นาที
- Check-in Close = Activity Start + 30 นาที
- Checkout Open = Activity End - 30 นาที
- Checkout Close = Activity End + 30 นาที
ผู้จัดกิจกรรมสามารถกำหนดเวลาเองตอนสร้างกิจกรรม

## Server enforcement
1. ตอนขอ Dynamic QR ระบบตรวจ Check-in Window
2. Token TTL สูงสุด 45 วินาที แต่ถูกตัดให้หมดอายุไม่เกิน Check-in Close
3. ตอนสแกน Check-in ระบบตรวจ Check-in Window ซ้ำ ไม่เชื่อ token เพียงอย่างเดียว

## Error states
- QR_CHECKIN_NOT_OPEN — ยังไม่เปิด Check-in
- QR_CHECKIN_CLOSED — ปิด Check-in แล้ว
- TOKEN_EXPIRED / INVALID_OR_EXPIRED_DEMO_QR — QR ใบเก่าหมดอายุ
- ACTIVITY_PARTICIPATION_NOT_ALLOWED — ไม่อยู่ในกลุ่ม/รายชื่อที่อนุญาต
- ALREADY_CHECKED_IN — มี Check-in แล้ว
- ACTIVITY_ALREADY_COMPLETED — เข้า–ออกกิจกรรมนี้ครบแล้ว

## Security rationale
การมี token ที่ยังดูถูกต้องไม่เพียงพอ ระบบต้องตรวจ policy ณ เวลาที่ทำ transaction เพื่อป้องกันการใช้ QR นอกช่วงเวลาที่กิจกรรมกำหนด
