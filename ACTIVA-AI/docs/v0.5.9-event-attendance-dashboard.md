# ACTIVA-AI V0.5.9 — Event-centered Attendance Dashboard

## เป้าหมาย
ลดภาระการค้นหารายการเมื่อกิจกรรมมีผู้เข้าร่วมหลักสิบถึงหลักร้อย โดยเปลี่ยนจากการแสดง card ใหญ่ทุกคนเป็น event-centered, exception-first workflow

## หน้าจอ
1. เลือกกิจกรรม
2. แสดง summary counts
3. ค้นหารหัส/ชื่อ
4. กรองสถานะ
5. แสดง compact rows 20 รายการต่อหน้า
6. แตะรายการเพื่อดูรายละเอียดหลักฐาน
7. กด “จัดการรายการ” เพื่อเชื่อมกับ Check-out / Staff Verification

## Filters
- ALL
- ACTIVE
- CHECKED_OUT
- WAIT_STAFF
- NEEDS_REVIEW
- NOT_EVALUATED
- VERIFIED

## Exception-first
สำหรับ ADMIN/ORGANIZER/STAFF ถ้ากิจกรรมมี record ที่ต้องตรวจสอบอย่างน้อยหนึ่งรายการ ค่าเริ่มต้นจะเปิด NEEDS_REVIEW แทน ALL

## Scope
V0.5.9 ทำ pagination ฝั่ง client สำหรับ prototype
เมื่อเชื่อม PostgreSQL จริงและมีข้อมูลจำนวนมาก ควรย้าย pagination/filter/search ไปฝั่ง API/SQL เพื่อรองรับหลักพันถึงหลักหมื่น records
