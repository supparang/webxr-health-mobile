# ACTIVA-AI V0.3.9 — Mobile Audit Trail

Audit Trail UI แยกข้อมูลออกเป็นสองชั้น:

## Human-readable layer
- เวลา
- เหตุการณ์ภาษาไทย
- ผู้ดำเนินการ
- บุคลากร
- กิจกรรม
- Decision
- เหตุผลผู้ตรวจ
- Blocker ภาษาไทย

## Technical layer
ซ่อนใน “ดูข้อมูลทางเทคนิค”
- action code
- entity type/id
- raw metadata JSON

การ enrich participant/activity context ทำตอนอ่าน Audit API เท่านั้น ไม่แก้ไขประวัติ Audit ที่เก็บไว้
