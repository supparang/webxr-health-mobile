# ACTIVA-AI V0.3.0 Research Gate

ลำดับการพัฒนา AI ถูกบังคับให้ผ่าน gate ดังนี้:

Raw Evidence
→ Independent Ground-Truth Labels
→ Adjudication
→ LOCK
→ ML Dataset Export
→ Train/Validation/Test Group Split
→ Baseline Model Comparison
→ Calibration
→ Locked Test Evaluation
→ Explainability Review
→ Human-in-the-Loop Deployment Review

## เหตุผลที่ยังไม่เปิด AI ในระบบสด
จนกว่าจะมี locked ground truth ที่เพียงพอและเหมาะกับ primary endpoint การเปิด risk probability ใน UI จะทำให้เสี่ยงต่อ data leakage, automation bias และการอ้างผลเกินหลักฐาน

## Model selection
เปรียบเทียบ Logistic Regression, Random Forest และ Gradient Boosting
โดยใช้ validation PR-AUC เป็นเกณฑ์เลือก model family ใน pipeline ตัวอย่าง

เกณฑ์นี้เป็น implementation default สำหรับ prototype ไม่ใช่ข้อสรุปว่าต้องเป็น primary endpoint ของ paper; protocol งานวิจัยต้องล็อก endpoint และ analysis plan ก่อน final test evaluation

## Final test
ผล final test ห้ามนำกลับไปปรับ feature, hyperparameter, threshold หรือ calibration
หากมีการปรับหลังดู test ต้องสร้าง/เก็บ independent test set ใหม่
