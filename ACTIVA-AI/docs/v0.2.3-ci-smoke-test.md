# ACTIVA-AI V0.2.3 — Continuous Integration and End-to-End Smoke Test

V0.2.3 เพิ่มระบบตรวจสอบอัตโนมัติใน GitHub Actions เพื่อป้องกันการพัฒนา prototype แล้ว flow หลักเสียโดยไม่รู้ตัว

## สิ่งที่ CI ตรวจ
1. ติดตั้ง dependencies
2. ตรวจ Prisma schema
3. สร้าง Prisma Client
4. สร้าง schema ใน PostgreSQL ชั่วคราว
5. seed ผู้ใช้และกิจกรรมตัวอย่าง
6. ตรวจ syntax ของ JavaScript
7. เปิด ACTIVA-AI server
8. ทดสอบเส้นทางจริง:
   - health
   - demo identity
   - users
   - activities
   - signed Dynamic QR
   - participant check-in
   - participant check-out
   - staff verification
   - rule-based evidence evaluation
   - blinded ground-truth queue
   - ground-truth label
   - human review
   - participant privacy filter
   - de-identified research export
   - audit trail

## Research safeguards ที่ CI ตรวจด้วย
- Ground Truth queue ต้องไม่มี aiPredictions
- Research export ต้องใช้ participant_hash ไม่ใช่ employee ID
- Rule-based Evidence Engine ต้องไม่ถูกอธิบายว่าเป็น AI probability
- Participant ต้องไม่เห็น attendance ของบุคคลอื่น
