# ACTIVA-AI V0.6.0 — Dual Dynamic QR Check-in/out

## หลักการ
เวลาอยู่ในช่วง Check-out เพียงอย่างเดียวไม่พิสูจน์ว่าบุคลากรยังอยู่ ณ จุดกิจกรรม

Normal flow:
CHECKIN QR → Participation → CHECKOUT QR → Evidence Engine

## QR Purpose
- CHECKIN ใช้ได้เฉพาะ Check-in Window
- CHECKOUT ใช้ได้เฉพาะ Check-out Window
- purpose mismatch ถูกปฏิเสธ
- token TTL สูงสุด 45 วินาที และไม่เกินเวลาปิดของ window

## Normal Checkout
ต้องมี:
1. Attendance record ที่ Check-in แล้ว
2. CHECKOUT QR token ที่ยัง valid
3. eventId ตรงกับ Attendance activity
4. อยู่ใน Checkout Window

## Exception Checkout
ADMIN/STAFF ใช้ /checkout-assist ได้เมื่อมีเหตุจำเป็น เช่น ออกจากงานก่อนเวลา หรือลืมสแกน
ต้องมี reason >= 10 ตัวอักษร
ระบบบันทึก:
- checkoutMethod = STAFF_ASSISTED
- checkoutQrValid = false
- checkoutExceptionReason
- Audit: STAFF_ASSISTED_CHECKOUT

Evidence Engine จะ flag STAFF_ASSISTED_CHECKOUT เป็น REVIEW_REQUIRED เพื่อให้ Human Review ไม่ถูกข้าม
