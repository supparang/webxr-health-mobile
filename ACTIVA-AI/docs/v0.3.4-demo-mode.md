# ACTIVA-AI V0.3.4 — Database-Free Demo Mode

วัตถุประสงค์ของโหมดนี้คือให้ทดลอง UX/UI และ workflow ของ ACTIVA-AI ได้ก่อนเชื่อม PostgreSQL จริง

## โหมด
### Demo Mode
- ไม่ต้องมี Node server
- ไม่ต้องมี PostgreSQL
- ใช้ localStorage ใน browser
- ข้อมูลเป็น DEMO / SYNTHETIC เท่านั้น
- เหมาะสำหรับ walkthrough, UX review, requirement review และการสาธิต

### Server Mode
- ใช้ Node/Express API
- Prisma
- PostgreSQL
- ใช้สำหรับ prototype ที่ต้องการ persistence และ research workflow จริง

## ข้อจำกัด
Demo Mode ไม่ใช่แหล่งข้อมูลวิจัยจริง ไม่ใช้เพื่อคำนวณผลวิจัยหรือประเมินประสิทธิภาพ AI

เมื่อ PostgreSQL พร้อม สามารถกลับมาเลือก Server Mode ได้โดยไม่ต้องเปลี่ยนหน้า UI
