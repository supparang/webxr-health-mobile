# ACTIVA-AI V0.2.2 — API-connected Prototype

## จุดเปลี่ยนสำคัญ
V0.2.2 เปลี่ยนหน้าเว็บจากการใช้ localStorage เป็น source of truth ไปใช้ PostgreSQL ผ่าน server-side API

อนุญาตให้เก็บ session reference ใน sessionStorage ได้ แต่ข้อมูลกิจกรรม การเข้า–ออก หลักฐาน การตรวจสอบ และ Ground Truth ต้องมาจาก API/ฐานข้อมูล

## Flow ที่เชื่อมแล้ว
Login (demo identity lookup)
→ Dashboard
→ Activity + Evidence Policy
→ Server-signed Dynamic QR
→ Check-in
→ Check-out
→ Staff Verification
→ Evidence Evaluation
→ Human Review
→ Ground Truth Labeling
→ Audit Trail
→ Research Export

## Privacy / RBAC
- PARTICIPANT เห็น attendance ของตนเองเท่านั้น
- PARTICIPANT Check-in และ Check-out ได้เฉพาะ record ของตนเอง
- ORGANIZER/STAFF/ADMIN ทำหน้าที่ตามสิทธิ์
- Audit และ Research Export จำกัด ADMIN
- Ground Truth จำกัด ADMIN/STAFF
- Ground Truth queue ไม่ดึง AIPrediction เพื่อคง blinded review

## AI
ยังไม่เปิด AI prediction อัตโนมัติ
ผล Evidence Engine ปัจจุบันคือ rule-based verification และต้องไม่เรียกว่า risk probability จาก AI

## หมายเหตุด้านการติดตั้ง
Docker Compose ใน prototype ใช้ prisma db push เพื่อให้ bootstrapping ทำงานได้แม้ยังไม่มี migration history ที่ล็อกแล้ว
ก่อน production ต้องสร้างและทดสอบ migration history อย่างเป็นระบบ
