# ACTIVA-AI V0.5.5 — Co-organizer Change Governance

## กติกา
### ก่อนเริ่มกิจกรรม
ผู้มีสิทธิ์ CAN_ASSIGN_CO_ORGANIZER สามารถเพิ่ม/ถอน Co-organizer ได้
ไม่บังคับเหตุผล

### ระหว่างกิจกรรม
ผู้มีสิทธิ์ยังแก้ไขได้ในกรณีจำเป็น
ต้องระบุเหตุผลอย่างน้อย 10 ตัวอักษร
Audit action: CO_ORGANIZER_CHANGED_DURING_ACTIVITY

### หลังสิ้นสุดกิจกรรม
รายชื่อ Co-organizer ถูกล็อกสำหรับผู้ใช้ทั่วไป
ADMIN เท่านั้นที่แก้ไขได้ โดยต้องระบุเหตุผล
Audit action: CO_ORGANIZER_ADMIN_OVERRIDE_AFTER_END

## UI
- แสดง lifecycle ของกิจกรรม
- แสดงเวลาบันทึกล่าสุด
- หลังเคยบันทึก ปุ่มเป็น “บันทึกการเปลี่ยนแปลง”
- ถ้าไม่มีการเปลี่ยนแปลง ระบบแจ้งว่า “ไม่มีการเปลี่ยนแปลงรายชื่อผู้จัดร่วม”

## Data model
Activity.assignmentsUpdatedAt ใช้แสดงเวลาบันทึกล่าสุด
รายละเอียดผู้แก้ไข เหตุผล รายการเพิ่ม/ถอน ถูกเก็บใน AuditLog
