# ACTIVA-AI V0.4.1 — Personnel & User Administration

## สิทธิ์
ADMIN:
- เพิ่มบุคลากร
- แก้ไขข้อมูลบุคลากร
- เปิด/ปิดบัญชี
- นำเข้า CSV

ORGANIZER / STAFF:
- อ่านรายชื่อเพื่อใช้ใน workflow ที่ได้รับสิทธิ์
- ไม่สร้างหรือแก้ไขบัญชีหลัก

PARTICIPANT:
- ไม่จัดการบัญชีบุคลากร

## การนำเข้า CSV
รองรับหัวคอลัมน์ภาษาไทย:
รหัสบุคลากร, ชื่อ, อีเมล, หน่วยงาน, บทบาท

หรือ:
employeeId,name,email,department,role

บทบาทใน bulk import:
PARTICIPANT / STAFF / ORGANIZER
หากระบุ ADMIN ใน CSV จะถูกลดเป็น PARTICIPANT เพื่อป้องกันการยกระดับสิทธิ์จากไฟล์จำนวนมาก

## Data integrity
ไม่ลบ User ที่มีประวัติใช้งาน ใช้ ACTIVE / INACTIVE เพื่อรักษาความสัมพันธ์กับ Attendance, Review และ Audit
