# ACTIVA-AI V0.8.0 — Verified Analytics & Management Dashboard

## เป้าหมาย
เพิ่ม analytics สำหรับการบริหารระบบโดยไม่ทำให้ข้อมูลที่ยังไม่ผ่าน Human Decision ถูกนำไปตีความเป็น outcome และไม่เปิดเผยข้อมูลส่วนบุคคลใน endpoint เชิงสรุป

## Operational analytics
ส่วนผลลัพธ์สุดท้ายใช้เฉพาะ `finalEvidenceStatus` ที่เป็น:
- VERIFIED
- OVERRIDE_VERIFIED
- REJECTED

รายการที่ยังไม่อยู่ในสถานะข้างต้นนับเป็น unresolved workload เท่านั้น

### ตัวชี้วัดหลัก
- recordCount
- finalizedCount
- unresolvedCount
- verifiedCount
- overrideVerifiedCount
- rejectedCount
- finalizationRate
- verifiedOutcomeRate
- averageReviewDurationSeconds
- averageResolutionHours

## Turnaround definition
`averageResolutionHours` วัดจาก:
attendance record createdAt → latest terminal Human Review reviewedAt

ข้อจำกัด:
ระบบยังไม่มี `reviewQueuedAt` โดยเฉพาะ จึงยังไม่ควรเรียกค่านี้ว่า Review Queue SLA

## Activity comparison
รายกิจกรรมแสดงเฉพาะข้อมูล aggregate:
- จำนวน record
- จำนวน finalized
- verified
- rejected
- unresolved
- finalization rate
- verified outcome rate

ไม่มี employeeId หรือชื่อบุคลากร

## Exception patterns
นับ reason/missing codes จาก Evidence Engine เฉพาะ case ที่ผ่าน Human Decision แล้ว
เพื่อไม่ให้ exception ที่ยังอยู่ระหว่างตรวจถูกตีความเป็นผลสุดท้าย

## Research snapshot
แยกจาก operational outcomes โดยชัดเจน

ประกอบด้วย:
- deployed model metadata
- locked ground truth count
- comparable model-ground-truth count
- agreement rate
- confusion matrix
- double-labeled case count
- reviewer agreement rate

Positive class ของ confusion matrix = `REVIEW_REQUIRED`

Research metrics เทียบ:
deployed-model prediction ↔ locked ground truth

ไม่ใช่:
AI score ↔ personnel performance

## Privacy & access control
- Endpoint: `GET /api/analytics/verified`
- Roles: ADMIN, STAFF
- Participant: 403
- `aggregated: true`
- `containsPII: false`
